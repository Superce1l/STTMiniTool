## v2.4.1 — 断行与等待提示（对齐上游 2.0.1 / 2.1.0）

本版只修断行与等待提示，对应上游 [QwenASRMiniTool](https://github.com/dseditor/QwenASRMiniTool) 2.0.1 / 2.1.0 已修、
而本分支同源的几类问题。推理、模型、打包方式与 v2.4.0 相同。

### ✍️ 中英混排不再逐字加空格
- 旧实现只要行内出现任意拉丁词就整行 `" ".join` → 「我们 play golf 吧」。
- 现在只在**相邻两个英文/韩文词**之间留空格：「我们play golf吧」；纯英文行不受影响。

### 🇰🇷 韩文保留词间空格
- 韩文与英文一样以空格分词：拼行、按词计数、孤儿行判定、纯文字(`.txt`)行间拼接都保留空格；
  此前「안녕 하세요」会被拼成「안녕하세요」。
- Whisper 对韩文挂 `-sow` 按词切段（`_SPACE_DELIMITED` 纳入 `ko`）。

### ⏸️ 长静音不再被并进同一行
- 相邻两字停顿 **≥2 秒** 一律断行，不再要求「行内已累积 ≥5 字」；
  「嗯 + 3 秒静音 + 好」现在分成两行，时间轴不再横跨静音（上游 #31 同类）。

### 🇯🇵 日文无标点长句在助词后换行
- 超过行宽且无停顿可退时，若行内含假名 → 在助词（は/が/を/に/で/と/も…）后换行；
  只在含假名的行启用，不影响中文断句。

### ⏱️ 已等待时间
- 运行中的队列行显示「识别中… · 已等待 32 秒」，模型加载状态同样追加已等待时间；
  长档不再像卡死（上游 2.1.0 同类）。

### 验证
- 新增 4 例断行回归（中英混排 / 韩文空格 / 长静音断行 / 日文助词断行），全套 189 例；
- 打包与 v2.4.0 一致：一次产出 **onedir** 与 **onefile** 两个 zip，均不含 CrispASR 核心与模型。

### 升级说明
- onedir 覆盖安装即可；onefile 解压替换 exe。`settings.json`、模型、队列归档（`queue-archive/`）沿用。
- 与 v2.4.0 相同：首次使用 GPU 核心时会自动下载上游最新 CrispASR。
